Chat model이란

모든 chat model의 세 가지 role.

Universal API.

OpenAI가 2023년 3월에 도입. Anthropic, Google, Meta, Mistral, 모든 open-weight chat template이 채택했다. 한 format, 모든 vendor.

이후의 모든 capability — tool, reasoning, agents — 가 이 세 role frame 안에 있다.

Model이 "생각"을 배웠다

Reasoning이 별도 channel이 되었다.

더 많은 token = 문제당 더 많은 compute. 중간 “thoughts”가 forward pass에 공간을 준다.

Part II

조종과 modern toolkit.

Steering, guardrails, 그리고 12개월 안에 도착한 네 가지 standards.

Steering & guardrailing

Model을 조종하는 두 축.

Constrain — 못 하게 막는다
  • Refusal training
  • Output filters
  • Sandbox — 세계가 read-only
  • 위험한 action 전의 permission prompt
Steer — 목적으로 유도
  • System prompt — job description
  • Structured output — schema 강제
  • Tool registry trimming
  • Verdict contracts — “PASS or FAIL로 끝내라”

규칙을 따르라고 부탁하지 마라 — 위반할 능력을 제거하라.

Part IV

Patterns & rifts.

다섯이 모두 합의하는 것. 그래도 합의하지 못한 곳.

Universal pattern

One loop. Many policies.

Multi-agent는 별도 platform이 아니다. 같은 loop을 다르게 configure한 것이다.

Universals — 더 이상 흥미롭지 않은 것

다섯이 모두 합의하는 것.

✓One loop, many policies
✓Methodology가 prompt에, state에 아니라
✓Compaction이 control flow의 일부
✓Streaming + parallel tool execution
✓SKILL.md + AGENTS.md as artifacts
✓ACP for editors, MCP for tools

“Uninteresting”은 positive — stable foundation이 있어야 designer들이 흥미로운 차이에 집중할 수 있다.

Canonical shape. Picker. 2026의 floor.

2026년의 AI agent란

Canonical shape.

Streaming chat loop over a provider abstraction — with tools, permissions, and extensions — 여러 runtime으로 configurable.

문제에 맞는 pattern을 골라라

옳은 질문은 — 내가 어떤 문제 class에 있는가? 그 답이 pattern을 고른다.

2026에 agent를 만든다면 — 이것이 floor

10가지 table stakes.

01 Streaming model + tool loop
02 Schema validation 있는 tool registry
03 SKILL.md loader
04 cwd에서 AGENTS.md walk
05 매 turn compaction stage
06 Permissions 또는 sandbox
07 MCP support 또는 명시적 refusal
08 ACP server
09 Durable session store
10 Subagent affordance

어느 것도 invent할 필요 없다. 흥미로운 일은 너의 문제 class에 어떤 pattern이 중요한지 고르고 — 나머지는 거부하는 것이다.
