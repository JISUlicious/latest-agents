Wave 이후

Framework 위에 discipline 정착.

남은 것
  1. Own your prompts.
    prompt: model에게 매 호출 보내는 지시. abstraction 뒤에 숨기지 말고 직접 작성하라.
  2. Own your context.
    context: model이 매 turn 보는 모든 것 (history + 문서 + tool 결과). 무엇이 들어갈지 직접 결정하라.
  3. Own your control flow.
    control flow: loop 그 자체 — 언제 model을 부르고, 언제 멈출지. framework에 맡기지 말고 직접 써라.
방법론의 수렴

모두가 orchestration layer는 작고 단순하게, integration layer는 더 정교하고 확장성있게.

Part II

Modern toolkit.

Steering, guardrails, 그리고 12개월 안에 도착한 네 가지 standards.

Steering & guardrailing

Two axes — Constrain & Steer.

Constrain — 행동 제약 사항
  • Refusal training
  • Output filters
  • Sandbox — host와의 격리
  • 위험한 action 전의 permission prompt
Steer — 행동 방식 유도
  • System prompt — job description
  • Structured output — schema 강제
  • Tool registry trimming
  • Verdict contracts — “PASS or FAIL 명시”

Prompt에 의존한 요청 대신 — 위험한 작업 기능 자체를 제한.
