Agent loop.

One revolution = one model call.

The model thinks. The agent loop runs tools. The result returns. The model thinks again. Repeats until done.

The foundation of every modern agent. Surfaces differ, the loop stays the same.

After the wave

Discipline settles on top of frameworks.

What remained
  1. Own your prompts.
    prompt: instructions sent to the model every call. Don’t hide them behind abstractions — write them yourself.
  2. Own your context.
    context: everything the model sees each turn (history + documents + tool results). Decide what goes in.
  3. Own your control flow.
    control flow: the loop itself — when to call the model, when to stop. Don’t outsource it; write it.
Where method converged

Everyone agrees: the orchestration layer stays small and simple; the integration layer becomes richer and extensible.

MCP became the de-facto standard for the integration layer in November 2024.

Part II

Modern toolkit.

Steering, guardrails, and four standards that arrived in twelve months.

Steering & guardrailing

Two axes — Constrain & Steer.

Constrain — what the agent cannot do
  • Refusal training
  • Output filters
  • Sandbox — isolation from the host
  • Permission prompt before risky actions
Steer — how the agent should act
  • System prompt — job description
  • Structured output — schema enforcement
  • Tool registry trimming
  • Verdict contracts — “declare PASS or FAIL”

Don’t ask politely via prompt — restrict the capability itself.
